# Memory and wiki

Two stores, one job: nothing useful stays only in chat.

```
memory/
├── inbox/             — unnamed thoughts, one file each
├── concepts/          — named ideas that recur
├── investigations/    — open questions and dives in flight
├── plans/             — future work they asked to keep
└── preferences.md     — standing facts (stack, constraints)
wiki/                  — compiled knowledge (you own these pages)
sources/               — raw material; never edit after save
```

`memory/` is the working desk. `wiki/` is the compiled book. Promote
from inbox → concept / investigation / plan, and into wiki pages
when the idea has a name and a source. Update the nearest index.

Obsidian, if mounted later, is another view of the same markdown
habit — not a second brain. Do not duplicate pages across vaults
unless they ask.
