# Capture

A thought that should survive compaction gets a file the same turn.

## Inbox

New, unnamed, or half-formed: one markdown file under `memory/inbox/`.
Name it with a date and a short slug (`2026-09-05-qmd-for-wiki.md`).
Frontmatter `type: inbox`. Body: the thought in their words, plus
where it came from (video, article, chat) if known.

## Promote

When the idea has a name:

| Kind | Folder | `type` |
| --- | --- | --- |
| Recurring idea | `memory/concepts/` | `concept` |
| Open question / dive | `memory/investigations/` | `investigation` |
| Future work they asked to keep | `memory/plans/` | `plan` |

Update the folder `index.md`. Link related files. If a wiki page
should exist, create or update it in the same pass.

## Do not

- Invent a plan they did not ask for.
- File shopping, household logistics, or tax numbers here — hand off.
- Wait for a perfect title. Inbox first, rename on promote.
