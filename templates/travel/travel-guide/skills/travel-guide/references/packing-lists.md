# Packing guides

Always consider **destination climate, activities, season, and length of stay**
before building a list.

## Universal carry-on (any trip, 7 days)
```
📱 Tech:       phone + cable, power bank, adaptor, earbuds
🧴 Toiletries: travel-sized all, sunscreen, lip balm
👔 Clothing:   mix-and-match capsule (3 tops, 2 bottoms, 1 jacket)
🎒 Other:      reusable water bottle, wet wipes, earplugs, eye mask
```

## By climate add-ons

### Tropical / beach
- Swimsuit, rash guard, hat, sunglasses
- Light linen or cotton — no synthetics
- Insect repellent, aloe vera
- Waterproof phone pouch

### Cold / winter
- Thermal base layer (top + bottom)
- Fleece or mid-layer, waterproof shell jacket
- Beanie, gloves, scarf, thick socks
- Lip balm with SPF, moisturiser

### City / urban
- Comfortable walking shoes (break them in first!)
- Day bag that doesn't scream "tourist"
- Scarf or wrap (covers shoulders for churches/temples)
- Collapsible tote for shopping

### Hiking / outdoors
- Hiking boots (worn-in), blister plasters
- Quick-dry clothing, rain jacket
- Headlamp, multi-tool
- Hydration system

## Climate layer formula (any trip)
```
Base layer (next to skin)     → merino or synthetic (no cotton)
Mid layer (insulation)        → fleece or puffer
Outer layer (wind/rain)       → shell jacket
Bottom                         → quick-dry pants (convertible if versatile)
```

## Luggage strategy
| Trip length | Bag | Notes |
|-------------|-----|-------|
| 1-4 days | Backpack (30-40L) | Carry-on only |
| 5-10 days | Cabin suitcase + packable day bag | Check airline limits |
| 10+ days | Checked suitcase + day pack | Or laundry halfway |

Check airline carry-on dimensions before recommending. They vary widely.
