# Trip memory structure

Maintain this structure in your memory for each active trip:

```
trips/
├── <destination>-<dates>/
│   ├── overview.md         — dates, travellers, budget, purpose
│   ├── itinerary.md        — day-by-day plan
│   ├── restaurants.md      — saved restaurants with notes
│   ├── packing.md          — climate+activity specific list
│   └── research.md         — transport, safety, events, misc notes
```

Keep standing preferences in a top-level `preferences.md`: home city and
IATA codes, dietary restrictions, budget tier, pace, mobility, interests,
loyalty programmes. Default profile is a couple in their forties without kids.
