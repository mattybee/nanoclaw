# Tax-year memory

Keep one folder per Australian financial year (1 July – 30 June):

```
tax-years/
├── 2025-26/
│   ├── overview.md        — lodging status, agent vs self, key dates
│   ├── income.md          — salary, rent, other
│   ├── deductions.md      — work, WFH, property, donations
│   ├── property.md        — rental schedule working, documents still needed
│   ├── super.md           — SG, salary sacrifice, cap headroom
│   └── questions.md       — items for the registered tax agent
├── 2026-27/
│   └── …
```

`memory/preferences.md` holds standing facts (age, retire-by-52, salary,
property, PHI, HELP). Year folders hold that year's numbers. Keep a
`retirement.md` note in memory when the 52–60 cash-flow plan changes.

When a year is being lodged, put the pack summary in `overview.md` so the
next session does not start from scratch.
